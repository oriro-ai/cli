# Oriro Feishu/Lark

Official Oriro channel plugin for Feishu and Lark workplace chats. Community maintained by @m1heng.

Install from Oriro:

```bash
oriro plugin add @oriro/feishu
```

Configure the Feishu/Lark app credentials in Oriro, then connect the plugin to the chats where agents should receive and send messages.

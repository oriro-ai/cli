# Advanced Fashion Design

## Pattern making and garment construction

### Flat pattern drafting

All garments start from a basic sloper — a fitted base pattern with no design ease.
**Basic bodice front:**

1. Center front line vertical. Bust level line horizontal.
2. Shoulder seam from neck point to shoulder point.
3. Armhole curve from shoulder point to side seam.
4. Dart intake: Bust dart converts ease to shape.
   **Measurements needed:** Bust, waist, hip, back length, shoulder width, neck circumference.

### Dart manipulation

Darts shape flat fabric into 3D curves. The bust point is the pivot point.
**Rotating darts:** Slash and spread method.
**Princess seam:** Dart converted to continuous shaping seam.

### Ease

**Wearing ease:** Minimum for comfort.
Bust: 2" close-fit, 4" fitted, 6" semi-fitted.
**Design ease:** Additional ease beyond comfort for aesthetic purposes.

## CLO3D (3D fashion CAD)

Virtual garment simulation. Draping simulation on 3D avatar.
**Workflow:** Import 2D pattern → Position around avatar → Sew seams → Simulate → Render.
Fabric properties: Weight, bend resistance, stretch determine simulation behavior.
Free student version available for educational use.

## Construction techniques

**Seam finishes:**
French seam: Encloses raw edges. For sheers and lightweight fabrics.
Flat-felled seam: Double-stitched, topstitched. Very strong. Denim jeans.
Serged/overlocked: Raw edges finished with overlocker. Industry standard.
**Pressing:** Press every seam as you sew. Unpressed garments look homemade.

## Grading

Grading: Scaling a pattern from one size to multiple sizes.
US standard grade: 1" increment between sizes at bust.
**Size chart (US women's):** Size 0: Bust 31.5", Waist 24", Hip 34.5".

## Production vocabulary

**Tech pack:** Technical specification document with measurements, construction details, BOM.
**Lead time:** Sample 2-4 weeks. Production 60-90 days typical.
**SKU:** Stock Keeping Unit — unique identifier per style/size/color.

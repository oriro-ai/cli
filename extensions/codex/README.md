# Oriro Codex

Official Oriro provider and harness plugin for OpenAI Codex app-server integration. It exposes the Codex-managed GPT model catalog and the Codex runtime surfaces used by Oriro agents.

Install from Oriro:

```bash
oriro plugin add @oriro/codex
```

Use this plugin when you want Oriro to run Codex-backed model turns, media understanding, and prompt overlays through the Codex app-server harness.

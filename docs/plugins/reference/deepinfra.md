# DeepInfra plugin

Adds DeepInfra model provider support to Oriro.

## Distribution

- Package: `@oriro/deepinfra-provider`
- Install route: npm; OriroHub: `orirohub:@oriro/deepinfra-provider`

## Surface

providers: deepinfra; contracts: imageGenerationProviders, mediaUnderstandingProviders, memoryEmbeddingProviders, speechProviders, videoGenerationProviders
